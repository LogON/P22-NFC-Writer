# P22 NFC Writer

*English version: [README.md](README.md)*

Android-приложение, которое записывает NFC-метку катушек **Olympia P22 / Nelko P21** на чистые
**NTAG213** (NTAG203 тоже подходит; NTAG216 принтер не принимает). Позволяет перемаркировать или
повторно использовать катушки, записав «код бумаги», по которому принтер опознаёт заправленный
рулон (размер, цвет, дизайн).

> **Дисклеймер.** Это независимый неофициальный инструмент для совместимости. Он **не связан с и не
> одобрен** Nelko, Olympia, Labelnise/Labelnize или JieLi. Названия продуктов и товарные знаки
> принадлежат их владельцам и используются только для описания совместимости. В репозитории **нет
> прошивки, ПО или изображений вендора** — превью рулонов приложение подтягивает в рантайме с
> публичного сервера вендора и кеширует на устройстве. Данные меток/каталога здесь (коды, размеры,
> имена) — это факт-данные для совместимости. Используйте на свой риск и только со своими катушками
> и оборудованием.

## Установка

Скачайте APK на странице [Releases](../../releases) и установите его (если Android спросит, разрешите
установку из неизвестных источников). Нужен телефон с NFC и Android 9 или новее.

## Использование

1. Выберите **Размер** и **Цвет / дизайн** или введите код из 24 hex-символов в поле **Код бумаги**.
2. Поднесите чистую NTAG213 к телефону. Приложение запишет страницы 4–7 и перечитает их для проверки.
3. Чтобы узнать код существующей катушки, отметьте **Прочитать метку вместо записи** и поднесите
   метку катушки к телефону.

## Как работает

На метке хранится 12-байтовый **код бумаги** (страницы 5–7), перед ним страница 4 `01 03 A0 0C`.
Шифрования и контрольной суммы на метке нет. Метку читает принтер, а официальное приложение Labelnise
ищет код в серверном каталоге и берёт оттуда размер, промежуток и фон-декор. Поэтому это приложение
**пишет коды из каталога**, а не собирает байты по полям.

- Этикетки, которые в каталоге числятся только за другими моделями, помечены, например `[P31S,P21]`.
- Каталог при запуске загружается с сервера Labelnise и кешируется; без сети берётся последняя копия,
  а если её нет — встроенный `app/src/main/assets/labels.json`. Превью рулонов качаются с сервера и
  кешируются.
- Под полем **Код бумаги** приложение показывает расшифровку размера и есть ли код в каталоге.

Формат подробно: [docs/TAG_FORMAT.ru.md](docs/TAG_FORMAT.ru.md). Дампы оригинальных катушек:
[docs/dumps](docs/dumps) (передал [mchangrh](https://github.com/merlinschumacher/nelko-p21-print/issues/2#issuecomment-3873826757)
под лицензией MIT, см. [#1](https://github.com/LogON/P22-NFC-Writer/issues/1)).

## Сборка из исходников

```bash
./gradlew assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`. Подписанные релизы собирает GitHub Actions,
см. [docs/RELEASING.ru.md](docs/RELEASING.ru.md).

## Инструмент make_tag.py

Собирает файл `.nfc` для Flipper Zero или печатает страницы 4–7 из каталога:

```bash
python tools/make_tag.py --catalog GAP22 -o gap22.nfc
python tools/make_tag.py --code 010204000301121215280C0F --pages
```

`tools/catalog_P21_P22.json` — факт-выгрузка публичного каталога (коды, размеры, имена, ссылки на картинки).
